# 🌍 Verified Tourist Guide Booking Platform (Web MVP)

A **web-first travel platform** designed for **foreign travelers visiting India**, enabling them to **discover verified local tourist guides**, **book them in advance**, **optionally share guides with other travelers**, and **communicate seamlessly through auto-translated chat**.

This repository contains the **MVP (Minimum Viable Product)** implementation.

---

## 🚀 Product Vision

To build a **trusted, language-independent travel platform** that removes friction for foreign travelers by offering:
- Verified local guides
- Transparent availability & pricing
- Advance booking
- Cross-language communication
- Safe shared guide experiences

---

## 🎯 MVP Goal

> Enable foreign travelers to easily find and book **verified tourist guides in India** through a secure, simple, and multilingual web experience.

---

## 👥 User Roles

### 🧳 Traveler (Foreigner)
- Explore Indian cities
- Discover verified guides
- Book guides in advance (login required)
- Optionally share a guide with other travelers
- Chat with guides in their preferred language

### 🧭 Tourist Guide (Individual)
- Register and submit verification documents
- Create and manage guide profile
- Set availability and pricing
- Accept or reject bookings
- Communicate with travelers via auto-translated chat

### 🛠 Admin
- Verify guide identities
- Approve or reject guide profiles
- View booking records (read-only)
